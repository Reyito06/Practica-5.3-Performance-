Práctica 5.3 - Pruebas de Performance

Evaluación del rendimiento

Este proyecto tiene como objetivo evaluar el rendimiento de una API mediante pruebas de carga, estrés y tiempo de respuesta.

Pruebas realizadas

1. Prueba de rendimiento

Evalúa el tiempo de respuesta de la API.

2. Prueba de carga

Simula múltiples usuarios realizando solicitudes.

3. Prueba de estrés

Evalúa el comportamiento de la API bajo una carga elevada.
